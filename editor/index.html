Frases que ELIZA dice al empezar.

Frases al terminar la conversación.

Si el usuario escribe alguna, la conversación termina.

Ejemplo: triste: triste, deprimido, mal, solo

Palabra clave + rango (prioridad) + respuestas (una por línea). Usa (2) para reutilizar lo que dijo el usuario.

Cómo funciona

ELIZA busca palabras clave. Gana la de mayor rango. Luego elige una respuesta al azar (o en orden).

Rango

Número de 0 a 10. Más alto = más prioridad cuando hay varias coincidencias.

Respuestas y (2)

Una por línea. (2) inserta el fragmento capturado por el patrón. Ejemplo: usuario dice «estoy cansado» → «¿Por qué estás (2)?» → «¿Por qué estás cansado?»

Sinónimos

Definen grupos. Si una regla usa @triste, reconocerá cualquier palabra del grupo «triste».

Vista Código

Puedes editar el JavaScript directamente. Al pulsar Aplicar se intenta parsear. Si hay error, la vista previa lo indica.

Descargar

Genera eliza-custom.js y probar-eliza.html. Colócalos junto a elizabot.js para probar fuera.
